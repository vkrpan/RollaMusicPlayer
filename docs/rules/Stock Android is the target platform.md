# Stock Android is the target platform

**Rule:** Rolla Music is mainly for stock Android. Platform-UI behaviour (System UI media card, notifications, launcher)
is accepted on stock Android; a Samsung One UI–only gap is a known limitation, not a blocker.

**Why:** One UI and stock Android differ in exactly these surfaces — e.g. [[One UI has no media resume card]].

**How to apply:** verify platform-UI features on a stock or near-stock device ([[Motorola edge 70]]) or an emulator.
Samsung-specific workarounds are low priority unless the user asks.
